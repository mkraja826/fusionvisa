# Fusion Abroad Services

Mobile-first 7-page marketing website for Fusion Abroad Services.

## Pages
1. Home
2. Services
3. Study Destinations
4. Scholarships
5. IELTS & Language Guidance
6. Education Loans
7. Contact / Free Counselling

## Brand palette
Extracted from the provided Fusion logo reference:
- Deep Indigo — #32377B
- Aviation Blue — #4B74AD
- Soft Blue — #A5B0CD
- Mist — #D0D8E8

Supporting neutrals are used for accessibility, contrast and premium UI depth.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The project uses Next.js App Router with static export.
